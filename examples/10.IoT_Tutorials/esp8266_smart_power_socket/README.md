# ESP8266 电源插座

基于 ESP-12F + HLW8032 插座的 SoftAP 厂商配网示例。打开同目录下的 `esp8266_smart_power_socket.ino`，填写 `THINGSCLOUD_PRODUCT_KEY` 后编译；不需要预置 WiFi 密码、ProjectKey 或 API/MQTT 地址。

## 硬件与依赖

- ESP8266 Arduino core 3.1.2，Generic ESP8266 Module，4MB Flash / 1MB LittleFS；更改分区前需制定数据迁移方案。
- ThingsCloud ESP SDK 1.0.17 或后续兼容版本、ArduinoJson 6.21.5、PubSubClient 2.8；SoftwareSerial 和 LittleFS 由 ESP8266 core 提供。
- 继电器 GPIO4，高电平吸合；按键 GPIO12，INPUT_PULLUP，按下接地；LED GPIO13，高电平点亮。其他板型需核对引脚和极性。
- HLW8032 通过 GPIO3/RXD 输入 4800 baud、8E1、24 字节 UART 帧。串口仅用 TX 输出 115200 调试日志，GPIO3 留给计量芯片。
- 继电器和计量芯片在仅 USB/3.3V 供电时可能无法完整工作；烧录与串口调试必须断开市电。

## 配网与控制

使用支持厂商配网的 ThingsX App 添加设备，连接 `SmartPower_XXXXXX` 热点。SDK 接收 App 提供的领取上下文，获取并保存平台接入凭据；重启后自动恢复。

短按 GPIO12 切换开关，立即请求上报 `switch`；平台下发同名布尔属性也可控制开关。上电先关闭继电器，再读取平台最新 `switch` 恢复状态；首次没有云端值时，以当前本地状态初始化。

长按超过 5 秒，LED 闪烁三次，清除 WiFi 和厂商接入凭据后重启。累计电量保留；平台解绑需另行操作。

## 平台属性与上报

| 标识符 | 类型 | 单位 | 用途 |
|---|---|---|---|
| `switch` | Bool / Switch | — | 设备云端共享，true 表示通电 |
| `voltage` | 数值 | V | 电压 |
| `current` | 数值 | A | 电流 |
| `power` | 数值 | W | 有功功率 |
| `energy_total` | 数值 | kWh | 设备累计用电量 |

每分钟完整上报以上五项；上线并正常取得云端开关状态后约 0.5～3 秒发起首次完整上报。网络异常、属性查询失败或平台限流时按退避逻辑重试，快速切换可能受平台消息频率限制。

所有数值最多三位小数；未读到、无效或超过 3 秒未更新的监测值填数值 0。内部累计计算保留原精度，每分钟保存一次，突然断电可能损失最后一分钟未保存的电量。电量以 HLW8032 脉冲计数累计，重启恢复时建立新的计数基准。

示例电压系数 1.88、电流系数 1.0 是参考值，不代表其他板型已校准；请根据采样电阻和标准仪表调整。该示例不提供计费或用电保护功能。

累计电量采用 LittleFS 双记录及 CRC 校验。仅在整个文件系统分区确认为空白时首次格式化；已有分区损坏时报告错误，不自动清空数据。请勿整片擦除后期待保留历史累计电量。
