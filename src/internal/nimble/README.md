# 蓝牙配网内部依赖

基于 [NimBLE-Arduino 2.5.1](https://github.com/h2zero/NimBLE-Arduino/tree/2.5.1)，保留上游许可与源码声明。此目录为 SDK 内部实现，不作为通用蓝牙 API 使用，也无需额外安装 NimBLE-Arduino。

仅面向同时具备 Wi-Fi 和 BLE 的 ESP32 芯片编译。关闭 Central、Observer、扩展/周期广播，最多一条连接，保留 Peripheral、标准广播和 GATT Server；密码学复用 mbedTLS。移除客户端、扫描器、HID、Beacon、Mesh 和非目标平台实现。标准 ATT 长读写和 MTU 256 保留；第一层消息缓冲池为 20 块，以覆盖 240 字节配网报文在低 MTU 下的长写分段和收发余量。实际手机长读写仍须真机验证。

除 nimconfig.h 配置、编译单元的芯片保护、内部 include 相对路径适配、默认回调延迟初始化、停止失败时保留活跃对象与未使用实现移除外，保留上游实现。版本升级须重新验证芯片编译与配网互通。不要同时链接另一份 NimBLE-Arduino。

SDK 的初始化错误处理保留设备数据：NVS 错误直接返回，不整库擦除；检查主机和任务创建结果，同步等待最多 10 秒；停止流程按阶段设置 5 秒等待上限。超时后保留相关同步对象，供后续安全重试；不能将清理过程的额外耗时算作已包含在 10 秒内。主机停止失败时不删除仍被使用的对象，由 SDK 报错并重试释放。硬件故障、低内存及低 MTU 手机互通仍须实测。
